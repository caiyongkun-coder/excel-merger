# Excel 表格整理程序 1.0

## 功能说明

本程序用于整理指定文件夹下的所有 Excel 文件，提取"用途"合并单元格覆盖的行数据，并格式化输出到新的 Excel 文件中。

### 主要功能

1. **批量处理**：自动读取输入文件夹下的所有 `.xlsx` 和 `.xls` 文件
2. **智能识别**：识别 A 列中包含"用途"关键词的合并单元格
3. **数据提取**：提取合并单元格覆盖的所有行数据
4. **格式化输出**：
   - 同行内容按列对齐（计算每列最大宽度，左对齐）
   - 不同行用换行符连接
   - 每个源文件对应一个 sheet
   - 格式化文本存储在 sheet 的 A1 单元格

## 安装依赖

```bash
pip install openpyxl xlrd
```

## 使用方法

### 基本语法

```bash
python excel_merger.py <输入文件夹> <输出文件名（不含扩展名）>
```

### 示例

```bash
# 处理 2026-02-28 文件夹下的所有 Excel 文件
python excel_merger.py /home/caiyongkun/caishufen/2026-02-28/ 2026-02-28

# 输出文件：2026-02-28.xlsx
```

## 输入要求

- **输入文件夹**：包含一个或多个 Excel 文件（.xlsx 或 .xls）的文件夹
- **Excel 文件格式**：
  - 首列（A 列）应包含合并单元格
  - 合并单元格内容应包含"用途"关键词
  - 示例：A9:A22 合并，内容为"用 途"

## 输出格式

- **文件名**：`<输出文件名>.xlsx`（固定为 .xlsx 格式）
- **Sheet 命名**：每个源文件对应一个 sheet，sheet 名 = 源文件名（不含扩展名）
- **内容格式**：每个 sheet 的 A1 单元格存储格式化后的合并文本

### 输出示例

```
日期        项目      金额      备注
2026-02-01  办公费    500.00    购买办公用品
2026-02-02  交通费    200.00    出差打车
2026-02-03  餐饮费    150.00    工作餐
```

## 注意事项

1. Sheet 名称长度不能超过 31 个字符（Excel 限制）
2. 如果源文件中未找到"用途"合并单元格，会跳过该文件并显示警告
3. 输出文件会覆盖已存在的同名文件

## 故障排除

### 问题：提示"未找到 Excel 文件"
**解决**：检查输入文件夹路径是否正确，确认文件夹中包含 .xlsx 或 .xls 文件

### 问题：提示"未找到包含'用途'的合并单元格"
**解决**：检查 Excel 文件首列是否有合并单元格，且内容包含"用途"关键词

### 问题：ModuleNotFoundError
**解决**：安装所需的 Python 库：
```bash
pip install openpyxl xlrd
```

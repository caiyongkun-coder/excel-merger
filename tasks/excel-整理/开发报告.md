## 功能说明

### 核心功能
- ✅ 批量处理指定文件夹下的所有 Excel 文件（.xlsx 和 .xls）
- ✅ 智能识别 A 列中包含"用途"的合并单元格（支持空格变体如"用 途"）
- ✅ 提取合并单元格覆盖的所有行数据
- ✅ 自动计算每列最大宽度，左对齐格式化
- ✅ 每个源文件对应一个 sheet，sheet 名=源文件名
- ✅ 格式化文本存储在 sheet 的 A1 单元格

### 技术特点
- 使用 openpyxl 处理 .xlsx 文件
- 使用 xlrd 处理 .xls 文件
- 智能关键词匹配（自动忽略空格）
- 列对齐格式化输出
- 完善的错误处理和用户提示

## 使用方法

```bash
# 安装依赖
pip install openpyxl xlrd --break-system-packages

# 运行程序
python excel_merger.py <输入文件夹> <输出文件名>

# 示例
python excel_merger.py /home/caiyongkun/caishufen/2026-02-28/ 2026-02-28
```

## 注意事项

1. 合并单元格必须在 A 列（首列）
2. 合并单元格内容需包含"用途"（支持空格变体）
3. Sheet 名称不能超过 31 个字符（Excel 限制）
4. 输出文件会覆盖已存在的同名文件
